FAQ

Häufige Fragen

Was kostet Milligate für Veranstalter?

Nichts. Es gibt keine Grundgebühr und keinen Vertrag, du bekommst 100 % vom Ticketpreis. Deine Gäste zahlen pro Ticket eine Servicegebühr von 0,89 € + 2,9 % vom Ticketpreis, höchstens 6,99 €.

Wie funktioniert die Altersgrenze?

Du stellst beim Event 16+ oder 18+ ein. Käufer bestätigen ihr Alter vor dem Kauf digital über unseren Dienstleister. Du bekommst nur das Ergebnis, keine Ausweiskopie.

Kann ich weiter an der Abendkasse verkaufen?

Ja. Milligate-Tickets erkennst du am Einlass per Scan, alles andere läuft wie gewohnt weiter.

Wann bekomme ich mein Geld?

Du verbindest einmal dein Bankkonto über Stripe. Die Ticketerlöse werden einen Tag nach deinem Event direkt an dich ausgezahlt. So ist bis zum Event sichergestellt, dass Gäste bei einer Absage ihr Geld zurückbekommen.

Was passiert, wenn die Party ausfällt?

Sagst du das Event im Creator Studio ab, bekommen alle Käufer ihr Geld automatisch zurück.
